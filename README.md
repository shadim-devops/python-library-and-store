# Python Library Manager & Online Store

Two small Python command-line demonstrations of object-oriented programming, using only the Python standard library.

## Projects

### Library manager (`library_manager.py`)
Models books, readers, and a city library. Demonstrates registering readers, adding and searching books, borrowing, returning, and viewing loans.

### Online store (`online_store.py`)
Models products, a shopping cart, customers, administrators, and orders. Demonstrates product inheritance, cart totals, and a simulated checkout. Pricing multipliers are illustrative, not production tax rules.

## Run

Requires Python 3. No external dependencies.

```bash
python library_manager.py
python online_store.py
```

Both scripts run example scenarios; they are not interactive applications. All sample customer information is fictional.
